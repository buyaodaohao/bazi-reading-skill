# bazi-reading-skill

八字命盘排盘与命理分析 Marvis Skill

## 功能

- **四柱排盘**：年柱（立春换年）、月柱（节气换月）、日柱（sxtwl 精准天文历法）、时柱（真太阳时校正后五鼠遁）
- **十神分析**：比肩/劫财/食神/伤官/正财/偏财/正官/七杀/正印/偏印
- **藏干十神**：地支藏干逐位标注十神
- **纳音**：六十甲子完整纳音
- **空亡**：日柱定空亡
- **五行旺衰**：天干+地支五行统计，身强身弱判断
- **用神喜忌**：身强→官杀/财/食伤为用；身弱→印/比为用
- **大运排盘**：阳男阴女顺排、阴男阳女逆排，精确节气起运（三日折一岁）
- **流年分析**：以立春为界，十神互动分析
- **开运建议**：佩戴、方位、颜色、行业、数字

## 使用方式

### 命令行

```bash
python3 scripts/bazi.py <年> <月> <日> <时> <分> "<地点>" "<性别>"
```

示例：

```bash
python3 scripts/bazi.py 1992 1 26 12 0 "河南省宝丰县闹店镇" "男"
```

参数说明：

| 参数 | 说明 |
|------|------|
| 年 月 日 | 公历或农历日期 |
| 时 分 | 出生时间（24小时制） |
| 地点 | 用于真太阳时校正 |
| 性别 | "男" 或 "女" |
| 第8个参数 | "true" 表示农历输入，默认公历 |

### 输出格式

输出 JSON 格式，包含 pillars（四柱）、shishen（十神）、canggan（藏干）、wuxing（五行统计）、dayun（大运）、liunian（流年）等完整命盘数据。

### 作为 Marvis Skill 使用

加载本 skill 后，调用脚本获取 JSON 数据，按 SKILL.md 中的结构展开完整命理分析（四柱表 → 五行旺衰 → 用神喜忌 → 性格 → 大运 → 流年 → 开运建议）。

## 技术细节

- **真太阳时校正**：根据城市经度计算时差，东八区城市约 -28min
- **年柱**：以立春为界，非农历正月初一
- **月柱**：以节气"节"为界（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）
- **起运**：三天折合一岁，余一天折四月
- **空亡**：以日柱所在旬确定
- **大运**：60甲子序数精确计算
